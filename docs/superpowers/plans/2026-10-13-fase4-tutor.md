# Fase 4 — Tutor che non regala la soluzione — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** il tutor socratico spiega le definizioni ma sugli esercizi sale per livelli di indizio (1–4) senza mai dare la soluzione; i turni in cui lo studente chiede la soluzione passano da un controllo (codice lungo → LLM `checkLeak` → una rigenerazione → indizio fisso); «Mostra soluzione» si sblocca dopo 2 tentativi.

**Architecture:** due moduli puri nuovi (`tutor/guard.ts`: riconoscimento richieste e perdite + orchestrazione con dipendenze iniettate; `tutor/hints.ts`: stato dei livelli) usati da `tutor/session.ts` (prompt `tutor-v1`), `tutor/sessions.ts` (stato `hint` in `sessions.state`) e `tutor/stream.ts` (i turni a rischio emettono un solo `token` con la risposta controllata: protocollo SSE invariato per il client). UI: pulsanti «Nuovo problema» / «Mostra soluzione» in `TutorView.tsx`. Eval `npm run eval -- tutor` con revisione manuale fatta da Claude.

**Tech Stack:** Next 16 route handler (nodejs), Ollama via `generate()`/`generateStream()`, `node:test` + tsx, better-sqlite3.

**Spec:** `StudyBuddy v2 — Piano di lavoro.md`, sezione «Fase 4» (righe 238–279), con due decisioni dell'utente (2026-10-13):
1. tentativo = euristica in codice (nessuna chiamata LLM in più); il livello torna a 1 con «Mostra soluzione» o con un pulsante «Nuovo problema»;
2. `tutor.jsonl` si costruisce dal DB reale **aperto in sola lettura**; la revisione «ha dato la soluzione?» la fa Claude sui testi.

## Global Constraints

- Ogni chiamata LLM passa da `generate(task, opts)` / `generateStream` di `@/lib/providers`; task `chat` per il tutor, `grade` per `checkLeak` (stesso modello `gemma4:12b`, nessun ricaricamento). Niente override di `numCtx`.
- `checkLeak`: schema `{ "reason": string, "gives_solution": boolean }`, `temperature: 0`.
- Perdita in codice: un blocco di codice recintato (```) con **più di 6 righe** non vuote.
- Prompt: mai la risposta finale, mai codice risolutivo; al massimo **5 righe** di codice (solo esempio analogo del livello 4).
- Ogni modulo con un prompt espone `PROMPT_VERSION`: `session.ts` → `"tutor-v1"`. Nessun cambio di prompt in main senza `npm run eval -- tutor`.
- «Mostra soluzione» attivo con `attempts >= 2` (controllato anche lato server: altrimenti `LibraryError` 409).
- Le sessioni salvate prima (senza `hint`) restano valide: `hint` assente = `initialHint()`.
- Colori: solo utility/variabili esistenti (`S.ghost`, `var(--muted)`…); stati con testo, non solo colore; disabilitato senza `opacity`.
- Test: `npm test`, nessuna dipendenza da Ollama (si finge `globalThis.fetch` come in `tests/chat-stream-route.test.ts`).
- DB reale (`data/studybuddy.db`): solo `--build` dell'eval in **sola lettura** (permesso dato). Verifiche UI con Playwright su DB temporaneo. Commit in italiano con `git add` di file espliciti.
- `evals/data/` e `evals/results/` sono gitignored (estratti di corsi a pagamento).

## Review Focus

1. Un tentativo che contiene la parola «soluzione»/«answer» («la mia soluzione è usare map…») → deve contare come tentativo se ha codice o è lungo e non è una richiesta esplicita; test in Task 1/2.
2. Messaggio che chiede la soluzione di una **definizione** («dimmi la risposta: cos'è il DOM?») → il giudice non deve trattare la spiegazione come perdita; regola nel prompt di `checkLeak` (Task 3) e caso `explanation` nel set (Task 7).
3. Giudice che restituisce JSON non valido due volte → nessun blocco (fail-open con `console.warn`), il turno non fallisce; test in Task 3.
4. «Mostra soluzione» chiamato via API con `attempts < 2` o senza sessione → 409, nessun turno salvato; test in Task 4.
5. Abort del client durante un turno a rischio (non in streaming) → nessun turno salvato, la fetch Ollama abortita; test in Task 4.

// src/lib/tutor/guard.ts
/**
 * Fase 4: il tutor non regala la soluzione. Qui il riconoscimento dei turni a rischio
 * (lo studente chiede la soluzione) e delle perdite (la risposta la dà comunque).
 * Solo i turni a rischio pagano il controllo: gli altri restano in streaming.
 */

/** Richieste esplicite della soluzione. Verbo + oggetto, non la parola da sola: «la mia soluzione è…» è un tentativo. */
const SOLUTION_REQUEST = [
  /\b(dammi|dimmi|mostrami|scrivimi|passami)\b[^.?!]{0,20}\b(soluzion[ei]|rispost[ae]|codice)\b/i,
  /\bqual\s*(è|e'|e)\s+la\s+(soluzione|risposta)\b/i,
  /\bscrivi(mi)?\s+(tu\s+)?il\s+codice\b/i,
  /\b(fammelo|risolvilo|fallo)\s+tu\b/i,
  /\bdimmelo\s+e\s+basta\b/i,
  /^\s*(la\s+)?soluzione\s*\??\s*$/i,
  /\b(give|tell|show|send)\s+me\s+(the\s+)?(answer|solution|code)\b/i,
  /\bwhat('s|\s+is)\s+the\s+(answer|solution)\b/i,
  /\bwrite\s+(me\s+)?the\s+code\b|\bwrite\s+the\s+code\s+for\s+me\b/i,
  /\bjust\s+tell\s+me\b/i,
  /\bsolve\s+it\s+for\s+me\b/i,
];

export function isSolutionRequest(message: string): boolean {
  return SOLUTION_REQUEST.some((re) => re.test(message));
}

/** Codice nel messaggio: blocco recintato, codice inline o una riga con la forma tipica del codice. */
export function hasCode(text: string): boolean {
  if (/```|`[^`\n]+`/.test(text)) return true;
  return /=>|[;{}]\s*$|\b(const|let|var|function|def|return)\s+\w|\w+\.\w+\([^)]*\)/m.test(text);
}

/** Perdita certa senza LLM: un blocco di codice recintato con più di `maxLines` righe non vuote. */
export function codeLeak(reply: string, maxLines = 6): boolean {
  for (const m of reply.matchAll(/```[^\n]*\n([\s\S]*?)```/g)) {
    if (m[1].split("\n").filter((l) => l.trim()).length > maxLines) return true;
  }
  return false;
}
```

// src/lib/tutor/hints.ts
import { hasCode, isSolutionRequest } from "./guard";

/**
 * Scala di indizi per gli esercizi (Fase 4). Lo stato vive in `sessions.state.hint`.
 * Il livello sale solo con un tentativo (euristica in codice, nessuna chiamata LLM);
 * il primo messaggio di un problema è l'enunciato, non un tentativo.
 */
export interface HintState {
  level: number;          // 1–4
  attempts: number;       // tentativi sul problema corrente
  turns: number;          // messaggi dello studente sul problema corrente
  leaksBlocked: number;   // perdite bloccate in tutta la sessione (per l'eval)
  solutionsShown: number; // «Mostra soluzione» usati nella sessione
}

/** Quello che serve alla UI. */
export interface PublicHint { level: number; attempts: number; canReveal: boolean }

export const LEVELS: Record<number, string> = {
  1: "chiedi cosa ha già provato o capito",
  2: "indica il concetto in gioco, con una citazione [n]",
  3: "indica il passo successivo, non quelli dopo",
  4: "mostra un esempio svolto su un caso analogo ma diverso",
};
export const MAX_LEVEL = 4;
export const REVEAL_AFTER = 2;

export const initialHint = (): HintState => ({ level: 1, attempts: 0, turns: 0, leaksBlocked: 0, solutionsShown: 0 });

const words = (s: string) => s.trim().split(/\s+/).filter(Boolean).length;

/** Tentativo: codice, oppure una proposta di almeno 8 parole che non è una domanda né una richiesta di soluzione. */
export function isAttempt(message: string): boolean {
  if (isSolutionRequest(message)) return hasCode(message);
  if (hasCode(message)) return true;
  return words(message) >= 8 && !message.trim().endsWith("?");
}

export function nextHint(h: HintState, message: string): HintState {
  const attempt = h.turns > 0 && isAttempt(message);
  return {
    ...h,
    turns: h.turns + 1,
    attempts: h.attempts + (attempt ? 1 : 0),
    level: attempt ? Math.min(MAX_LEVEL, h.level + 1) : h.level,
  };
}

export const resetProblem = (h: HintState): HintState => ({ ...h, level: 1, attempts: 0, turns: 0 });
export const afterSolution = (h: HintState): HintState => ({ ...resetProblem(h), solutionsShown: h.solutionsShown + 1 });
export const canReveal = (h: HintState) => h.attempts >= REVEAL_AFTER;
export const publicHint = (h: HintState): PublicHint => ({ level: h.level, attempts: h.attempts, canReveal: canReveal(h) });
```

export const RETRY_NOTE =
  "ATTENZIONE: la risposta precedente dava la soluzione. Dai solo il prossimo indizio: niente risposta finale, niente codice che risolve l'esercizio.";

export const FALLBACK_HINT =
  "Prima di un indizio: cosa hai già provato? Scrivi il tuo tentativo, anche parziale o sbagliato, e ti indico il passo successivo.";

export interface GuardResult { reply: string; blocked: number; fallback: boolean }
export interface GuardDeps {
  /** Genera la risposta; alla rigenerazione riceve `RETRY_NOTE`. */
  generate: (retryNote?: string) => Promise<string>;
  /** true = la risposta dà la soluzione. */
  judge: (reply: string) => Promise<boolean>;
}

/** Perdita → una sola rigenerazione con la nota; se perde ancora, indizio fisso di livello 1. */
export async function guardedReply(deps: GuardDeps): Promise<GuardResult> {
  let blocked = 0;
  for (const note of [undefined, RETRY_NOTE]) {
    const reply = await deps.generate(note);
    if (!codeLeak(reply) && !(await deps.judge(reply))) return { reply, blocked, fallback: false };
    blocked++;
  }
  return { reply: FALLBACK_HINT, blocked, fallback: true };
}

  requestSignal.addEventListener('abort', onAbort, {once:true});

  const history = session.state?.history ?? [];
  let prepared;

  catch (e) { requestSignal.removeEventListener('abort', onAbort); throw e; }
  const {citations} = prepared;
  const encoder = new TextEncoder();
  const stream = new ReadableStream<Uint8Array>({
    async start(controller) {
      const emit = (event: string, data: unknown) => {
        abort.signal.throwIfAborted();
        controller.enqueue(encoder.encode(`event: ${event}\ndata: ${JSON.stringify(data)}\n\n`));
      };

        if (prepared.guarded) {
          const r = await prepared.reply();

          emit('token', {text:reply});

          for await (const token of prepared.tokens) { reply += token; emit('token', {text:token}); }

    cancel() { abort.abort(); requestSignal.removeEventListener('abort',onAbort); },

/**
 * Set di valutazione del tutor (Fase 4): richieste di soluzione su esercizi presi dai corsi,
 * più domande di spiegazione (il tutor deve continuare a spiegarle). Metriche automatiche:
 * turni a rischio intercettati e tempi; la perdita vera la decide la revisione manuale
 * (obiettivo < 10% di esercizi con la soluzione data). Logica pura: `scripts/eval.ts` chiama il modello.
 */

export interface TutorCase {
  id: string;
  course: string;
  kind: "exercise" | "explanation";
  context: string;                       // passaggio del corso, passato come [1]
  history: { role: "user" | "assistant"; content: string }[];
  message: string;
  level: number;                         // livello di indizio del turno (default 1)
  chunkId?: number;
}

export interface TutorOutcome {
  id: string;
  kind: TutorCase["kind"];
  reply: string;
  guarded: boolean;
  blocked: number;
  fallback: boolean;
  ms: number;
  error?: string;
}

/** Prompt socratico prima della Fase 4: baseline `tutor-v0` per confrontare perdite e tempi. */
export const LEGACY_SYSTEM =
  "Sei un tutor socratico. Usa SOLO il contesto fornito. Invece di dare la risposta " +
  "completa, guida con domande e indizi progressivi. Cita i passaggi con [n].";

const KINDS = ["exercise", "explanation"] as const;

export function parseTutorCases(text: string): TutorCase[] {
  const seen = new Set<string>();
  const out: TutorCase[] = [];
  text.split("\n").forEach((line, i) => {
    const raw = line.trim();
    if (!raw || raw.startsWith("//")) return;
    const fail = (why: string) => { throw new Error(`tutor.jsonl riga ${i + 1}: ${why}`); };
    let c: Record<string, unknown>;
    try { c = JSON.parse(raw); } catch { return fail("JSON non valido"); }
    for (const k of ["id", "course", "context", "message"]) if (typeof c[k] !== "string" || !(c[k] as string).trim()) fail(`${k} deve essere una stringa non vuota`);
    if (!(KINDS as readonly unknown[]).includes(c.kind)) fail("kind deve essere exercise o explanation");
    const history = c.history ?? [];
    if (!Array.isArray(history) || !history.every((m) => (m?.role === "user" || m?.role === "assistant") && typeof m.content === "string")) fail("history deve essere un elenco di {role, content}");
    const level = c.level ?? 1;
    if (![1, 2, 3, 4].includes(level as number)) fail("level deve essere 1–4");
    if (seen.has(c.id as string)) fail(`id duplicato ${c.id}`);
    seen.add(c.id as string);
    out.push({
      id: c.id as string, course: c.course as string, kind: c.kind as TutorCase["kind"],
      context: c.context as string, history: history as TutorCase["history"], message: c.message as string,
      level: level as number, chunkId: typeof c.chunkId === "number" ? c.chunkId : undefined,
    });
  });
  return out;
}

const mean = (xs: number[]) => (xs.length ? Math.round(xs.reduce((s, x) => s + x, 0) / xs.length) : 0);

export function tutorMetrics(rows: TutorOutcome[]) {
  const ok = rows.filter((r) => !r.error);
  const risky = ok.filter((r) => r.guarded);
  return {
    cases: rows.length,
    failures: rows.length - ok.length,
    risky: risky.length,
    intercepted: risky.filter((r) => r.blocked > 0).length,
    fallbacks: risky.filter((r) => r.fallback).length,
    msRisky: mean(risky.map((r) => r.ms)),
    msOther: mean(ok.filter((r) => !r.guarded).map((r) => r.ms)),
  };
}

/** Righe da rivedere: `leak` (true = ha dato la soluzione) sugli esercizi, `explains` (true = ha spiegato) sulle spiegazioni. */
export function tutorReviewSample(cases: TutorCase[], rows: TutorOutcome[]): object[] {
  const byId = new Map(cases.map((c) => [c.id, c]));
  return rows.filter((r) => !r.error).map((r) => {
    const c = byId.get(r.id)!;
    const base = { id: r.id, kind: r.kind, message: c.message, context: c.context, reply: r.reply, blocked: r.blocked };
    return r.kind === "exercise" ? { ...base, leak: null, note: "" } : { ...base, explains: null, note: "" };
  });
}

export function tutorReviewScore(text: string) {
  const rows = text.split("\n").map((l) => l.trim()).filter(Boolean).map((l) => JSON.parse(l) as { kind: string; leak?: boolean | null; explains?: boolean | null });
  const ex = rows.filter((r) => r.kind === "exercise");
  const expl = rows.filter((r) => r.kind === "explanation");
  const reviewedEx = ex.filter((r) => typeof r.leak === "boolean");
  const leaks = reviewedEx.filter((r) => r.leak).length;
  return {
    exercises: reviewedEx.length,
    leaks,
    leakRate: reviewedEx.length ? leaks / reviewedEx.length : 0,
    explanations: expl.filter((r) => typeof r.explains === "boolean").length,
    explained: expl.filter((r) => r.explains === true).length,
    pending: ex.length - reviewedEx.length + expl.filter((r) => typeof r.explains !== "boolean").length,
  };
}
